# 仕様: 使い方タブ

最終更新: 2026-09-01

関連: [project-overview.md](./project-overview.md)

## 1. 役割

アプリの概要と各機能の説明を **機能画面とは分離** して載せるタブ。

- ナビラベル: **使い方**（`TabId: howto`）
- PC / スマホで説明の一部を出し分け（`useMediaQuery`）
- 操作ヒントやレイアウトの補足は **ここに書き、機能画面には書かない**

## 2. 記載内容（目安）

- 単価メモの目的
- 買い物メモ（追加・保存・試算・単位入力）
- スマホのスワイプ削除（引き切り式、開いたカード対応）
- フォルダタブ（品目・店名・検索・記録・複製編集）
- 値段推移（グラフ・店舗一覧・絞り込み・記録詳細の見方）
- 記録フォームの各欄の意味（購入日・店・値段・内容量・単位）
- 単価の考え方（総額÷内容量、100単位表示、読みがな）

**機能画面には操作ヒントを書かない**（検索結果など、その場の状態を示す短文のみ可）。

## 3. 実装パス

`frontend/src/features/guide/components/HowToPage.tsx`
