# 仕様: 値段推移（`FolderTrendPanel`）

最終更新: 2026-09-01

関連: [project-overview.md](./project-overview.md) / [spec-folders-catalog.md](./spec-folders-catalog.md)

## 1. 役割

品目（フォルダ）ごとに、厳密単価の **時系列グラフ** を表示する。店舗ごとの絞り込みは **店舗一覧** から行う（旧「店舗比較」は廃止）。

| 入口 | 条件 |
|------|------|
| フォルダタブ（PC） | 品目カードのグラフボタン → 右側分割パネル（`compact`） |
| 値段推移タブ（スマホ） | `lg` 未満のみナビに表示。フォルダを `<select>` で選択 |

PC では独立の **値段推移タブは非表示**（`App.tsx` で `hiddenTabs: ['trends']`）。

## 2. 画面構成（上から）

1. **単位・表示** … 単位セレクト、100単位あたり / 単位あたり
   - スマホ: 折りたたみボタン（現在の設定を表示）
   - PC: 常時表示
2. **グラフ** … Recharts 折れ線（時系列1本。未選択時は全店舗の点を1系列に）
3. **記録の詳細** … グラフ上の点を選んだときのみ表示（選択が無いときは何も出さない）
4. **店舗一覧** … 件数・平均・最安。店舗名でソート（五十音）

店舗を絞り込み中は、グラフ直上に **「○○の記録を表示中」＋「すべて表示」** を出す（操作UI。使い方の説明は書かない）。

### 補足テキストの置き場

機能画面内に操作ヒント（「タップすると…」等）を置かない。**使い方タブ**（`HowToPage`）に集約する。

## 3. グラフ操作

| 操作 | PC | スマホ |
|------|-----|--------|
| 記録の選択 | マウスを横軸上で動かす（インデックスを座標から算出） | 点をタップ |
| グラフ外へカーソル | **最後に合わせた記録の詳細を残す** | — |
| 選択解除 | — | グラフ余白タップ |

ホバー用の Recharts `Tooltip` は使わない。

## 4. 店舗一覧

- 見出し: **店舗一覧**（「店舗比較」ではない）
- 各店: **件数 / 平均 / 最安** のみ（最高・直近は表示しない）
- 集計は **全店舗の点**（`allPoints`）から算出。グラフの絞り込み状態とは独立
- **クリック / タップ** でその店の記録だけグラフに反映
- もう一度同じ店を選ぶ、または「すべて表示」で全店舗に戻す
- 選択中の行・カードはハイライト

### レイアウト

| 画面 | 店舗一覧 |
|------|----------|
| PC（分割パネル） | 2列グリッドのカード |
| スマホ | 1列カード。統計は1行3列（件数・平均・最安） |

## 5. データ処理

- `toTrendPoints` … 単位フィルタ後、日付順ソート
- `summarizeByStore` … 店舗ごとに件数・平均・最安
- かな検索は店舗一覧には未使用（フォルダ・メモ・カタログ検索で使用）

実装: `frontend/src/features/trends/utils/aggregate.ts`
