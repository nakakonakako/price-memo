# 仕様: フォルダタブ（品目名・店名カタログ）

最終更新: 2026-09-06

関連: [project-overview.md](./project-overview.md) / [spec-shopping-memo.md](./spec-shopping-memo.md)

## 1. 役割

フォルダタブは **記録データのハブ** である。

| 概念 | テーブル | 意味 |
|------|----------|------|
| 品目名（フォルダ） | `price_folders` | 比較したい商品集合の棚。記録は必ずここに属する |
| 店名（店舗） | `price_stores` | 店舗名の正規カタログ。記録の `store_name` と整合させる |
| 記録 | `price_records` | 購入日・店・値段・数量などの厳密データ |

買い物メモの一覧は **別管理**（`price_memo_items`）。フォルダタブで棚を作っても、メモに載せない限り店頭一覧には出ない。

## 2. UI 構成

### 2.1 タブ内切替

画面上部で **品目名** / **店名** を切り替える（検索していないとき）。レイアウトは共通:

- 先頭の水色カード … 追加（＋）
- グリッド … カード一覧（品目は琥珀色、店名は緑色）
- 虫眼鏡ボタンで検索欄の表示切替（常時表示ではない）
- 検索欄 … **フォルダ名・店舗名を横断**（かな横断。`lib/kanaSearch.ts`）。入力中は品目・店名の両セクションに候補を出す
- 並び … **追加順（新しい順）** または **名前順**
- 検索中は **新規＋カードを非表示**（横断結果のため追加カード自体を出さない）

通常時は他タブと同様 **中央寄せ**（`max-w-3xl`）。ヘッダー（アプリ名・タブ切替）は常に中央のまま。

### 2.1b プレビュー展開と詳細ビュー

- カード本体をタップ → **直近 3 件**の記録プレビューを展開（複製・編集可）
- プレビュー行は **1 行コンパクト**:
  - 日付は短い表記（同年は `9/6`、別年は `26/9/6`。`formatShortRecordedAt`）
  - 総額／内容量のみ（円/g などの単価は出さない）
- 詳細への入口:
  - プレビュー下部の **「すべての記録を見る」**（または「記録一覧を開く」）
  - 件数バッジをタップ
- 詳細は同一タブ内の画面切替（URL ルートではない）。「← 一覧へ」で戻る。開いたときは **ページ先頭へスクロール**
- 品目詳細・店名詳細: 全記録は **購入日の新しい順（降順）**。並べ替え UI なし
- 詳細でも複製・編集・削除は可能。記録データはマウント時の `listAllRecords` から派生（不足時のみ `listRecords`）

カタログ側カードは件数・▸・＋。展開はプレビューのみ（無制限の縦伸びはしない）。

### 2.1c ページ上部へ戻る

買い物メモ・フォルダ一覧・記録詳細で、ある程度スクロールすると右下に **↑**（四角いボタン）を表示（`ScrollToTopButton`）。  
PC でゴミ箱ドラッグ中は重ならないよう非表示。

### 2.1d パフォーマンス・タブ同期

- タブはアンマウントせず keep-alive（`App.tsx`）。初回訪問時だけマウント
- フォルダ／記録の変更は `lib/catalogSync.ts` の revision。他タブを再表示したとき差分があれば静かに再取得
- 店舗一覧は `storesCache`（`StoreField` / `ensureStore` で共有）
- 値段推移パネル（recharts）は lazy 分割。開いたときだけ読み込み

### 2.2 品目名カード

- 表示名は末尾の `()` / `（）` 内の **読み** を一覧では非表示（ソート・検索では利用）
- 例: 保存名 `牛乳（ぎゅうにゅう）` → 表示 `牛乳`、名前順は `ぎゅうにゅう` 基準
- 鉛筆（名前変更）は品目名の直右。小さく薄い `quiet` スタイル
- 右端: **値段推移（PC）**・記録件数（タップで詳細）・▸・**記録追加（＋）**
- カード本体タップでプレビュー展開。詳細は件数／「すべての記録を見る」から
- 記録行: **複製**・**編集**
- 記録の編集は **モーダル**。編集時に **品目（フォルダ）の変更** 可

### 2.3 値段推移パネル（PC のみ）

`lg`（1024px）以上でのみ利用。スマホではグラフボタン非表示 → **値段推移タブ** を使う。

1. 品目カードのグラフボタンを押す
2. カタログ全体が **アニメーション** で左半分へ、右半分に推移グラフ＋店舗一覧
3. ヘッダー（単価メモ・タブ）は中央位置のまま動かさない
4. 記録の追加・編集・削除はパネルを閉じずにグラフへ反映
5. もう一度グラフボタンで元の中央レイアウトへ

PC では独立の **値段推移タブは出さない**（フォルダ内パネルに統合）。

詳細: [spec-trends.md](./spec-trends.md)  
実装: `FolderTrendPanel`（`frontend/src/features/trends/components/`）

### 2.4 店名カード

- 品目名と同様のヘッダー（件数・▸・記録追加）
- タップで **詳細ビュー**（当店舗の記録一覧・全フォルダ横断）
- 記録追加（＋）… モーダルで **品目（フォルダ）を選択** し、店名は事前入力
- 店名変更時は、同店名の既存記録の `store_name` も一括更新

### 2.5 ドラッグ・ゴミ箱・スワイプ

| 対象 | PC | スマホ |
|------|-----|--------|
| 品目名カード | ゴミ箱へドロップで削除（記録あり→確認）。ゾーンは **ドラッグ中のみ** | 左スワイプ削除 |
| 店名カード | 同上（記録は残る） | 左スワイプ削除 |
| フォルダ内記録 | ゴミ箱削除（並べ替えなし）。ゾーンは **ドラッグ中のみ** | 左スワイプ削除 |

`DraggableCatalogItem` … PC は `TrashDragItem`、スマホは `SwipeToDeleteRow`。  
ドラッグ中は元要素を `display: none` にし、プレースホルダのみ残す（二重空き防止）。

スマホの `SwipeToDeleteRow`（買い物メモ・フォルダ共通）:

- 左へ十分スワイプ（幅の約 45%、最低 96px）で削除、未満なら元に戻る
- 途中で削除ゾーンを開いたまま止める操作はない

PC の削除ゾーン（`MemoTrashZone`）はコンテンツ右端〜画面右端の帯。**買い物メモ・フォルダともドラッグ中のみ** 破線・ゴミ箱を表示。

## 3. 記録の追加・編集モーダル

- `RecordForm` … 購入日は `date-field-wrap`（スマホで日付欄のはみ出し抑制）
- 数量と単位は横並び。単位列はやや広め（`6.5rem`）
- 単位「その他…」は内容量行の下にインライン入力（`UnitField`、モーダルなし）

## 4. 店舗名の入力（アプリ全体）

記録保存時の店舗は **自由入力ではなくカタログ指定** を基本とする。

- UI: `StoreField`（検索＋一覧から選択、未登録は「〇〇を店舗に登録」）
- 保存時: `ensureStore` で `price_stores` に登録し、正規名を `price_records.store_name` に書く
- 既存記録からのバックフィルで `price_stores` を初期化済み

対象画面: フォルダタブの記録モーダル、買い物メモの保存フォーム など。

## 5. 新規品目の追加フロー

1. 先頭の＋カードを押す
2. `新しいフォルダ` 等の仮名で作成（**追加順では末尾**）
3. 即座に名前編集状態（名前順表示時は追加カードの隣に固定し、保存後にソート位置へ）
