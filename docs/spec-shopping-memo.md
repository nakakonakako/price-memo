# 仕様: 買い物メモ（店頭での使い方）

最終更新: 2026-08-27

関連: [spec-split-receipt-and-unit-price.md](./spec-split-receipt-and-unit-price.md) / [project-overview.md](./project-overview.md)

## 1. 一文まとめ

B は支出管理アプリではなく **厳密単価の統計アプリ** である。  
店頭では値札 OCR より、**事前に載せた比較対象の統計（平均・最安・直近）を見ながら棚と照合**する。単位換算と比較は買い物メモ上の短い試算で行い、必要ならその場で1件保存する。

## 2. 背景（店頭照会 OCR を本流にしない）

当初想定した「店頭照会」（値札写真 → OCR → 自動判定）は、次の理由で存在意図が薄い。

| 論点 | 内容 |
|------|------|
| 事前準備で足りる | 買う候補をフォルダ／メモに載せ、平均・最安を見ておけば棚と目視照合できる |
| 未掲載は追記でよい | 載っていない商品はメモに足せばよい |
| 自動化と思想がずれる | B はマニュアル・確定データ前提。OCR 本流はコストに見合わない |
| 本当に必要な計算 | 棚は総額＋容量、メモは単価。必要なのは **短い単位換算と比較** であり、写真パイプラインではない |

**結論**: 値札 OCR による店頭照会は **本流にしない（延期／非目標寄り）**。代わりに **買い物メモ** を店頭の主画面にする。

## 3. プロダクト上の位置づけ

| 概念 | 意味 |
|------|------|
| 本アプリ | 厳密な値段推移・店舗比較のための **データ統計** |
| 買い物メモ | 店頭で開く **統計ビュー＋その場試算（＋任意保存）** |
| 記録 | 履歴の編集・A からの任意下書き・詳細 CRUD |
| 買わなかったデータ | 統計として残してよい（見た価格も単価比較の材料になる） |

支出の有無を厳密に分けることは必須にしない（必要なら後からメモ欄や任意フラグで足せる）。

## 4. 画面の役割分担（仮）

| 画面 | 役割 |
|------|------|
| **買い物メモ** | 店頭の主。フォルダ一覧に平均／最安／直近。行内で今の値札を試算。任意で `price_records` へ保存 |
| **フォルダ** | 棚（比較対象集合）の作成・改名・削除・中身一覧 |
| **記録** | 厳密レコードの詳細登録・編集。A レシートからの任意下書き |
| **値段推移** | 1フォルダのグラフ・店舗比較（深い分析） |
| **レシート紐付け** | 完成済みレコードへの事後参照（需要は低い。将来の A ジャンプ用。独立タブは見直し可） |

「記録タブで入れてからメモタブで見る」の二度手間を避けるため、**店頭の入力はメモ上で完結**させる。

## 5. 買い物メモの最小仕様（実装前の仮決め）

### 5.1 一覧（各フォルダ行）

常に見せる（レコードが1件以上ある場合）:

- フォルダ名
- 表示単位（例: 円/100g。フォルダ内の優勢単位に合わせる）
- **平均単価 / 最安単価 / 直近単価**（同一単位に揃えたもの）
- 件数

レコード0件のフォルダは「まだ統計なし」と出し、試算・初回保存は可能にする。

### 5.2 行内試算（単位換算＋比較）

短い入力:

- 今の総額（円）
- 数量 + 単位（g / ml / 個）
- 店名（保存する場合は必須寄り。試算だけなら任意でも可 → 実装時に確定）

出力:

- 今の単価（単位あたり／100単位あたり）
- 平均・最安・直近との差（例: 平均より安い／最安に近い、数値で併記）
- 小さい推移は **任意**（初版は数字比較だけでよい。グラフは値段推移タブに任せる）

数量が確定できないときは単価判定を出さない（仮定値禁止と一貫）。

### 5.3 任意保存

- `統計に残す` → 既存の `price_records` に1件追加（`recorded_at` = 確認日／購入日）
- 保存しなくても試算結果は見られる
- 買った／見て終わったの区別は初版必須にしない

### 5.4 「得」の初版定義

初版はシンプルに:

- **平均より安いか**
- **最安との差**
- **直近との差**

しきい値付きのラベル（「かなり安い」等）は後回しでよい。

## 6. 典型フロー

### 6.1 買い物前

1. 比較したいものをフォルダに入れておく（またはメモ一覧に載る状態にする）
2. メモで平均・最安を把握して出かける

### 6.2 店頭

1. 買い物メモを開く
2. 該当フォルダの統計を見る
3. 棚の総額と容量を行内試算に入れる → 得かどうか判断
4. 残したければ `統計に残す`（買わなくても可）
5. メモに無い商品はフォルダ追加 or 既存フォルダへ保存

### 6.3 帰宅後・メンテ

- 記録タブで修正、A からの下書き登録
- 値段推移タブで深い比較

## 7. 非目標（この仕様の範囲外）

1. 値札／パッケージ写真の OCR を本流の店頭フローにすること
2. A が無いと店頭判断できないこと
3. 試算結果を A 待ちの未完成レコードとして保存すること
4. 買い物メモを家計簿ダッシュボードにすること

OCR やラベル写真は、将来も「手入力がつらい場面の補助」以上には位置づけない。優先度は買い物メモより下。

## 8. 実装メモ

- UI タブ: `買い物メモ`（`memo`）。アプリ起動時の初期タブ
- データは新規テーブルなし。`price_folders` + `price_records` の集計＋試算 UI
- 既存の trends 集計（優勢単位・100単位換算）を再利用
- 実装パス: `frontend/src/features/memo/`
