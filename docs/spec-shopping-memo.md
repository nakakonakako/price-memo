# 仕様: 買い物メモ（店頭での使い方）

最終更新: 2026-09-01

関連: [spec-split-receipt-and-unit-price.md](./spec-split-receipt-and-unit-price.md) / [project-overview.md](./project-overview.md) / [spec-folders-catalog.md](./spec-folders-catalog.md)

## 1. 一文まとめ

B は支出管理アプリではなく **厳密単価の統計アプリ** である。  
店頭では値札 OCR より、**メモに載せた比較対象の統計（平均・最安・直近）を見ながら棚と照合**する。単位換算と比較は買い物メモ上の短い試算で行い、必要ならその場で1件 `price_records` に保存する。

## 2. フォルダタブとの関係（重要）

| | フォルダタブ | 買い物メモ |
|--|-------------|------------|
| 一覧の意味 | 全品目（フォルダ）・全店舗の **マスタ** | 店頭用の **ピン留めリスト** |
| データ | `price_folders` / `price_stores` | `price_memo_items`（`folder_id` 参照） |
| 追加 | マスタに作成 | 既存フォルダを検索して載せる、または新規名でフォルダ作成＋メモ追加 |
| ゴミ箱 | 品目削除 or メモから外す | **メモから外すだけ**（フォルダ・記録は残る） |

フォルダタブで棚を作っても、メモ一覧には自動では出ない。店頭で見たいものだけメモに載せる。

## 3. メモへの追加 UI

「＋ メモを追加」で折りたたみパネルを開く。**1つの品目名入力欄**に統合している。

1. 品目名を入力すると、メモ未掲載の既存フォルダが **候補リスト** で表示される（行タップでメモ追加）
2. **追加** ボタン … 既存名と一致すればそのフォルダをメモに載せる。未登録ならフォルダ作成＋メモ追加
3. 検索は **かな横断**（ひらがな入力でカタカナ名にもヒット）。`lib/kanaSearch.ts`
4. ブラウザの自動補完は出さない（`autocomplete="off"`、`datalist` 不使用）

## 4. 一覧（各メモ行）

レコードが1件以上ある場合:

- 品目名（フォルダ名の表示名。末尾読みは非表示）
- 表示単位に揃えた **平均 / 最安 / 直近**
- 複数単位がある場合は単位切替ボタン

レコード 0 件でも試算・初回保存は可能。

## 5. 行内試算・保存

- 入力: 確認日、店名（`StoreField`・カタログから選択）、総額、内容量、単位、補足
- **店名を選ぶと、平均／最安／直近はその店の記録だけで計算**（未入力時は全体）
- 店名は保存時に `price_stores` へ登録され、記録に正規名が入る
- `統計に残す` → `price_records` に1件追加（フォルダはメモ行の `folder_id`）
- 試算だけなら保存不要

## 6. 並べ替え・削除

| 環境 | 並べ替え | メモから外す |
|------|----------|--------------|
| PC | ドラッグ。右端の削除ゾーンは **ドラッグ中のみ** 表示 | 削除ゾーンへドロップ |
| スマホ | なし | 左スワイプ（`SwipeToDeleteRow`） |

並べ替えは `price_memo_items.sort_order` を更新。ゴミ箱はフォルダ本体を削除しない。

## 7. 典型フロー

### 店頭

1. 買い物メモを開く（初期タブ）
2. 載せたい品目が無ければ検索または新規でメモに追加
3. 統計を見ながら行内試算 → 必要なら保存
4. メモに無い品目はフォルダタブで棚を整備してからメモに載せる

### 帰宅後

- フォルダタブで記録の修正・追加
- **PC**: フォルダタブの値段推移パネルで分析（[spec-trends.md](./spec-trends.md)）
- **スマホ**: 値段推移タブで分析

## 8. 非目標

- 値札 OCR を店頭本流にすること
- メモ一覧 = 全フォルダの自動ミラー
- 試算結果の A 待ち未完成レコード

## 9. 実装パス

- `frontend/src/features/memo/`
- API: `frontend/src/features/memo/api/memoApi.ts`（`price_memo_items`）
