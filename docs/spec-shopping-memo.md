# 仕様: 買い物メモ（店頭での使い方）

最終更新: 2026-10-21

関連: [spec-split-receipt-and-unit-price.md](./spec-split-receipt-and-unit-price.md) / [project-overview.md](./project-overview.md) / [spec-folders-catalog.md](./spec-folders-catalog.md)

## 1. 一文まとめ

B は支出管理アプリではなく **厳密単価の統計アプリ** である。  
店頭では値札 OCR より、**メモに載せた比較対象の統計（平均・最安・直近）を見ながら棚と照合**する。単位換算と比較は買い物メモ上の短い試算で行い、必要ならその場で1件 `price_records` に保存する。

## 2. フォルダタブとの関係（重要）

| | フォルダタブ | 買い物メモ |
|--|-------------|------------|
| 一覧の意味 | 全品目（フォルダ）・全店舗の **マスタ** | 店頭用の **ピン留めリスト** |
| データ | `price_folders` / `price_stores` | `price_memo_items`（`folder_id` 参照） |
| 追加 | マスタに作成 | 既存フォルダを検索して載せる、または新規名でフォルダ作成＋メモ追加 |
| ゴミ箱 | 品目削除 or メモから外す | **メモから外すだけ**（フォルダ・記録は残る） |

フォルダタブで棚を作っても、メモ一覧には自動では出ない。店頭で見たいものだけメモに載せる。

## 3. メモへの追加 UI

「＋ メモを追加」で折りたたみパネルを開く。**1つの品目名入力欄**に統合している。

1. 品目名を入力すると、メモ未掲載の既存フォルダが **候補リスト** で表示される（行タップでメモ追加）
2. **追加** ボタン … 既存名と一致すればそのフォルダをメモに載せる。未登録ならフォルダ作成＋メモ追加
3. 検索は **かな横断**（ひらがな入力でカタカナ名にもヒット）。`lib/kanaSearch.ts`
4. ブラウザの自動補完は出さない（`autocomplete="off"`、`datalist` 不使用）
5. 操作ヒント文は画面に出さない（[使い方タブ](./spec-guide.md) に集約）

## 4. 一覧（各メモ行）

レコードが1件以上ある場合:

- 品目名（フォルダ名の表示名。末尾読みは非表示）
- 表示単位に揃えた **平均 / 最安 / 直近**
- 複数単位がある場合は単位切替ボタン

レコード 0 件でも試算・初回保存は可能。

カードを開いているときだけ、品目名行の右に二次的な文字ボタン **「フォルダへ」** を出す。閉じたカードには出さない。長い品目名は省略したまま、ボタンは行の右に残す。押してもカードは開いたまま（折りたたみ・PC のゴミ箱ドラッグ・スマホのスワイプ削除とは別操作）。遷移は URL を変えず、`App` が一時的な要求（要求 id 付き）を持ってフォルダタブへ切り替える。フォルダタブは表示中かつ対象フォルダの読み込み後にだけ、既存の `openFolderDetail` で詳細を開く（開いたときの先頭スクロールもそのまま）。同じフォルダを続けて開く場合も、要求 id が変わるのでそのたび詳細を開く。

初期ロードは `listFolders` + `listMemoItems` のあと、メモ掲載フォルダだけ `listRecordsForFolders`（全記録は取らない）。
メモへ新規追加した品目は一覧の **先頭**（`sort_order` を既存最小より小さくする）。

## 5. 行内試算・保存

- 入力: 確認日、店名（`StoreField`・カタログから選択）、総額、内容量、単位、補足
- 確認日と店名は 2 列（`minmax(0, 1fr)`）。確認日はネイティブ `input type="date"`（`DateInput`）。枠線・角丸・背景・余白はラッパーが持ち、入力本体に padding はない
- **単位「その他…」** … モーダルではなく内容量の下にテキスト欄。入力中は下書きのみ、フォーカスが外れたときに確定（`UnitField`）
- **店名を選ぶと、平均／最安／直近はその店の記録だけで計算**（未入力時は全体）
- 店名は保存時に `price_stores` へ登録され、記録に正規名が入る
- `統計に残す` → `price_records` に1件追加（フォルダはメモ行の `folder_id`）
- 試算だけなら保存不要

## 6. 並べ替え・削除

| 環境 | 並べ替え | メモから外す |
|------|----------|--------------|
| PC | カード全体をドラッグ。右端の削除ゾーンは **ドラッグ中のみ** 表示 | 削除ゾーンへドロップ |
| スマホ | 行右端の **専用ハンドル** のみでドラッグ（挿入位置を線表示、先頭・末尾・キャンセル可）。ハンドルにフォーカスした **上下キー**（Shift+上下で先頭・末尾）やハンドル上の短い縦スワイプでも1段移動。`touch-action: none` はハンドルだけ | 左スワイプ（`SwipeToDeleteRow`） |

スマホのスワイプ削除:

- **途中で止めて削除ボタンを出す状態はない**（引き切るか元に戻るかのみ）
- 幅の約 45%（最低 96px）以上左へスワイプして離すと削除、未満ならスナップバック
- カードを開いた入力フォームの余白など、入力欄以外からもスワイプ可能（フォーム全体の `data-no-trash-drag` は付けない）

並べ替えは DB の `reorder_price_memo_items` RPC で **1 回の操作**として `sort_order` を更新する。操作開始時の並び（期待順）と操作後の並び（希望順）を渡し、サーバー側の現在順（`sort_order`, `created_at`, `id`）と一致しない場合は `PM001` で失敗する（自動再試行はしない。一覧を再取得し、ユーザーに再度並べ替えを促す）。RPC 成功前は保存完了として扱わない。失敗後の再取得にも失敗した場合は一覧順を未確認として明示し、直前の表示順に戻す。並べ替え RPC の同時送信・古い応答は generation で無視する。ゴミ箱はフォルダ本体を削除しない。
新規追加は先頭（より小さい `sort_order`）。ドラッグ並べ替え後もその順を永続する。

メモから外す削除は **非冪等** とする。対象行がすでに存在しない場合は0件を成功扱いせず、他端末での削除または利用不可の可能性を案内して、メモ一覧を再取得する。

## 6b. ページ上部へ戻る

ある程度スクロールすると右下に ↑（四角いボタン、`ScrollToTopButton`）。フォルダタブでも同様。PC でゴミ箱ドラッグ中は非表示。

## 6c. パフォーマンス（メモ）

- 既定タブのため、記録取得は掲載フォルダに限定
- タブは keep-alive（`App.tsx`）。他タブでのフォルダ／記録変更は `catalogSync` の revision で、再表示時に差分同期
- 別デバイスなど外部からの更新は `resumeSync`（`visibilitychange` / `window.focus` / `pageshow`）で再取得。表示中タブは復帰直後、非表示の keep-alive タブは次に表示されたときに再取得。`catalogSync` の revision とは別経路。通信失敗時は既存表示を維持し、次の復帰で再試行
- Private Broadcastで `price_folders` / `price_records` / `price_memo_items` の変更を受けた場合もpayloadを適用せず既存APIで再取得する。表示中は即時、非表示中は次回表示時に更新し、カードの展開・入力下書き・並びを維持（[Realtime同期仕様](./spec-realtime-sync.md)）
- フォルダタブで品目（フォルダ）を **DB 削除** したときは、削除成功直後に `catalogSync` の folder-delete 通知で買い物メモ（非表示中も）が対象 `folder_id` のメモ行・記録・フォルダ候補を即時除去する。他カードの並び・展開・入力下書きは維持し、一覧全体の半透明ロックは使わない。削除前に始まった取得や並べ替え RPC の古い応答では復活させない（generation と一時 tombstone）。再取得で削除対象が確認できなければ tombstone を解除する。残存が返った場合は一度再取得し、なお残る場合は不整合エラーを表示して tombstone を解除する。再取得自体に失敗した場合は tombstone を保持し、次の再同期で再確認する。いずれの場合も他カードは操作可能のまま
- 店舗一覧は `storesCache` を共有し、作成・改名・削除は stores revision でマウント済み StoreField にも同期する。記録保存時の `ensureStore` による新規作成も同じ通知経路を通る

## 7. 典型フロー

### 店頭

1. 買い物メモを開く（初期タブ）
2. 載せたい品目が無ければ検索または新規でメモに追加
3. 統計を見ながら行内試算 → 必要なら保存
4. メモに無い品目はフォルダタブで棚を整備してからメモに載せる

### 帰宅後

- フォルダタブで記録の修正・追加
- **PC**: フォルダタブの値段推移パネルで分析（[spec-trends.md](./spec-trends.md)）
- **スマホ**: 値段推移タブで分析

## 8. 非目標

- 値札 OCR を店頭本流にすること
- メモ一覧 = 全フォルダの自動ミラー
- 試算結果の A 待ち未完成レコード

## 9. 実装パス

- `frontend/src/features/memo/`
- API: `frontend/src/features/memo/api/memoApi.ts`（`price_memo_items`）
